# Progressive Lens Education Simulator

Interactive 3D educational app built with Three.js, TypeScript, and Vite.

## Development

```bash
npm install
npm run dev
```

Open the URL printed by Vite.

## Build

```bash
npm run build
npm run preview
```

## Notes

- Default language is Persian (RTL); use the language button for English (LTR).
- WebGL is required; a fallback message is shown when unavailable.
- No patient data is stored or transmitted.
